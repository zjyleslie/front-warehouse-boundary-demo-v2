# Streamlit在线部署步骤

## 第一次部署

1. 登录GitHub，新建一个仓库，例如 `front-warehouse-demo`。
2. 将本文件夹中的内容上传到仓库根目录。不要上传 `.venv`、缓存文件或原始订单压缩包。
3. 打开 `https://share.streamlit.io` 并使用GitHub账号登录。
4. 选择创建应用，然后选择刚建立的仓库。
5. 分支选择 `main`，入口文件填写 `streamlit_app.py`。
6. 点击部署，等待依赖安装和页面启动。
7. 打开生成的 `streamlit.app` 地址，测试154、552和553单三个需求点，再检查细化门槛图和过程回放。

## 公开还是私有

本文件包只包含脱敏汇总数据和模拟订单编号，可以部署为公开演示。如果以后加入原始订单文件，必须改用私有仓库和私有应用，并重新检查下载功能。

## 汇报前检查

1. 提前一天使用学校网络打开应用。
2. 汇报前十分钟再次打开，避免应用处于休眠状态。
3. 将网址写入PPT并生成二维码。
4. 手机开启热点作为备用网络。
5. U盘中保留离线HTML和完整文件夹。

## 更新应用

修改本地文件后，将改动重新上传到同一GitHub仓库。Streamlit会自动读取新版本。更新后依次检查页面顶部是否显示543至553单/日、552单时纯人工最低、553单时现场零人最低。
