# 两分钟汇报操作顺序

## 第一步 说明研究基准

停留在页面顶部，说明订单记录口径、完整日需求基线和细化后的门槛范围。

建议表述：

本研究使用课题组提供的32个日期文件，共4,798笔订单级记录。完整日样本为31天、4,761笔。扩大复验后，模型门槛的95%范围为543至553单/日。

## 第二步 展示当前成本排序

向下滚动到论文条件基准，指出154单/日时纯人工成本约39.61万元，现场零人约41.77万元，人机协作约66.13万元。

## 第三步 改变需求量

将日订单量从154切换到450，再切换到552和553。

建议表述：

350至450单/日逐单复验后，1名人工配置仍保持较高成功率。552单/日时纯人工最低，553单/日时现场零人最低。中心门槛为552至553单/日。

## 第四步 展示细化门槛

滚动到细化容量门槛图，指出552单的Wilson下限为95.06%，553单降到93.81%。浅橙色区域表示2,000次Bootstrap得到的543至553单/日范围。

## 第五步 展示过程回放

选择人机协作方案，拖动一天中的时间滑块，展示到达、等待、拣选、工作站处理和完成订单数的变化。

将时间调到1140分钟，展示两笔订单正在拣选。再调到1440分钟，展示当天订单全部完成。

## 第六步 说明参数依据

最后停在稳健性与参数依据部分，说明设备价格、寿命和维护率按研究假设设定，后续可使用正式报价和真实班表更新模型。
